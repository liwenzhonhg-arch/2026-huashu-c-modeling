# 模型验证报告

## 总体评价
需修改。模型总体框架覆盖四个子问题，任务边界、储能状态、可观测性和有限输出处理较完整，也没有错误使用准确率、召回率或混淆矩阵等不可观测监督指标。但新能源利用率口径、问题一前序未完成任务衔接、问题四Pareto归一化方向和情景输出存在会改变优化结论的错误，当前应判定为阻断。

## 逐项检查

### 公式正确性
- [问题] 式(31)只计入新能源直接消纳和外送，遗漏题面明确要求的新能源充电量 \(R_{rt}^{ch}\)。问题三、四的统一利用率应为
  \[
  U_{\mathrm{RE}}=
  \frac{\sum_{r,t}(R_{rt}^{use}+R_{rt}^{ch}+R_{rt}^{sell})\Delta t}
  {\sum_{r,t}R_{rt}^{av}\Delta t}.
  \]
  当前公式会低估储能吸收新能源的贡献，并错误影响问题四的Pareto解。
- [问题] 式(63)–(65)没有统一指标方向。成本、碳排放、时延和峰值为越小越好，服务质量和新能源利用率为越大越好；若直接使用原始 \(Q_{\mathrm{service}}\) 和 \(U_{\mathrm{RE}}\)，其理想值通常大于最劣值，将因条件 \(z_j^{nadir}>z_j^{ideal}\) 被排除，导致折中方案未实际权衡全部目标。
- [问题] \(\omega_{it}(s)\)被定义为小时数，但式(3)直接计算为MW、式(18)直接与GPU容量比较，量纲分别成为MWh和GPU-hour。虽然 \(\Delta t=1\) h时数值相同，仍应定义无量纲占用比例 \(\alpha_{it}(s)=\omega_{it}(s)/\Delta t\)，或在负荷和容量公式中显式除以 \(\Delta t\)。
- [问题] \(P_r^{peak}\)和 \(z_{rt}\)只有下界。在不直接最小化这些辅助变量的方案中可能存在松弛，不能直接把变量值当作实际峰值和爬坡量报告；应在结果阶段由 \(N_{rt}\)复算，或增加确定其最小可行值的二级目标。
- [通过] 储能SOC递推、充放电效率方向、能量平衡、终端SOC以及充放电互斥公式正确。
- [通过] WAPE、新能源零分母、空任务集和退化Pareto维度均设置了有限输出分支，不会正常地产生NaN或Inf。

### 量纲一致性
- [问题] 式(3)、式(18)、式(19)混用了重叠时长与占用比例。必须显式使用 \(\omega/\Delta t\)，才能分别得到MW和等效GPU。
- [通过] 成本、碳排放、SOC递推、网络时延和等效循环次数的其余量纲基本一致。

### 约束完整性
- [问题] 问题一仅把“2376小时前已开工且尚未完成”的任务放入 \(\mathcal I^{carry}\)。2376小时前到达、但基础调度安排在2376时或以后开工的弹性任务既不属于 \(\mathcal I^{carry}\)，也不属于最后24小时到达任务集合 \(\mathcal I^{end}\)，会从调度和容量约束中消失。必须传递所有截至2376仍未完成的前序任务，包括尚未开工但已有固定计划的任务；或者将这些任务与最后24小时任务联合重优化。
- [问题] 问题四滚动窗口方法没有定义全时域碳预算、平均时延、新能源利用率和服务质量阈值在窗口间的剩余预算传递规则。仅在拼接后审计可能得到违约后停止，但不能使每个窗口中的ε约束模型成为完整可执行模型。
- [问题] 问题四要求比较不同售电价格机制，但情景模型只改变购电峰谷价差，没有定义任何 \(c_{rt}^{sell}\) 情景，无法生成其“必须回答的输出”第6项。
- [通过] GPU、IT功率、设施功率、网络时延、任务截止、2406禁占用、购售电边界和储能边界均已纳入。
- [通过] 问题二新能源外送采用分源守恒，未重复计入负荷侧平衡。

### 参数合理性
- [通过] \(H=168\) h、固定ε锚点和300秒共享预算均给出了固定可执行值，没有依赖未搜索的文献参数。
- [通过] 外部搜索明确标记为未执行，模型没有把未搜索范围冒充文献事实，也没有提前声称已得到拟合参数或验证结果。
- [问题] 波动情景采用截断正态扰动后一般会改变新能源均值，因此同时混合了“波动增强”和“平均水平变化”。这不会单独阻断模型，但若要解释为纯波动效应，应在截断后重新校准均值，或明确报告实际均值变化。

### 可求解性
- [问题] 在滚动窗口中缺少全局ε预算的状态传递，使问题二、四声明的全时域ε约束不能直接按当前步骤实现。至少需要传递累计碳排放、累计时延分子、累计新能源利用量及剩余可用预算。
- [问题] 五点ε网格若对多个区域峰值阈值同时做笛卡尔积，候选数量可能指数增长；模型虽有统一截止时间，但没有预声明受预算约束的有限候选选取规则。应固定联合锚点路径或固定最大候选数。
- [通过] 各子模型在修正上述问题后可表示为MILP或正则化回归，且设置了限时可行解和结构化停止规则。

### 数据可观测性
- [通过] 预测需求标签可由实际任务表聚合得到；调度和储能没有真实最优标签，模型正确使用硬约束残差、守恒复算、完成率和求解状态进行验证。
- [通过] 未使用准确率、召回率、混淆矩阵或虚构的监督学习标签。
- [通过] 模型阶段没有声称已经获得RMSE、WAPE、最优值或“通过验证”，相关结果均保留给后续代码执行。

### 结果常识性
- [问题] 遗漏新能源充电会把“新能源先充储能后使用”的合理策略误判为新能源未利用，可能使联合优化倾向直接外送而非储能消纳，违反题目统一评价口径。
- [问题] 若直接报告松弛的 \(P_r^{peak}\) 或 \(z_{rt}\)，可能出现报告峰值高于真实最大净购电、爬坡量高于真实绝对变化的非常识结果。
- [通过] 模型已设置容量、功率、SOC、购售电、时延、截止和任务连续执行等现实约束，未发现无界能源套利或无限输出。

## 修改建议
1. 将问题三、四的新能源利用率统一改为计入 \(R^{use}+R^{ch}+R^{sell}\)，并同步修改结构化方程、Pareto指标和审计公式。
2. 将重叠时长和占用比例分开定义：
   \[
   \alpha_{it}(s)=\omega_{it}(s)/\Delta t,
   \]
   GPU与功率约束使用 \(\alpha\)，GPU-hour统计使用 \(\omega\)。
3. 问题一在2376时传递全部未完成前序任务：已开工任务传递固定剩余占用，尚未开工任务传递其已承诺方案，或纳入末端MILP重新优化。
4. 将所有Pareto指标先转成“越小越好”的损失量，例如 \(1-Q_{\mathrm{service}}\) 和 \(1-U_{\mathrm{RE}}\)，再执行式(63)–(65)归一化。
5. 为滚动优化显式定义累计状态和剩余ε预算，不能只依赖拼接后的失败审计。
6. 增加固定、有限的售电价格机制情景，并保留题目要求的原结果名称。
7. 峰值和爬坡量从最终 \(N_{rt}\)轨迹直接复算；如需在模型内使用辅助变量值，则增加二级最小化以消除松弛。
