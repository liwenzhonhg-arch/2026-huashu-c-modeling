# 模型验证报告

## 总体评价
需修改。任务调度、SOC 递推、可观测性和终端边界总体合理，但问题二至问题四的能源平衡存在重复计算新能源外送的实质性错误。该错误会导致购电量、成本、碳排放、新能源利用率及储能策略全部失真，必须修正后才能求解。

## 逐项检查

### 公式正确性
- [问题] 问题二同时使用
  \[
  U_{rt}^{RE}+P_{rt}^{sell}+P_{rt}^{curt}=A_{rt}^{RE}
  \]
  和
  \[
  P_{rt}^{buy}+U_{rt}^{RE}=P_{rt}^{fac}+P_{rt}^{sell}.
  \]
  联立后得到
  \[
  P_{rt}^{buy}+A_{rt}^{RE}
  =P_{rt}^{fac}+2P_{rt}^{sell}+P_{rt}^{curt},
  \]
  外送功率被重复计入一次，违反附件统一能源平衡式。
- [问题] 问题三的分源方程也存在相同错误。新能源守恒已经把 \(P^{sell}\) 作为新能源去向，但分源电力平衡又将其列在右端。两式联立后外送功率被计算两次，因此文中所称其与附件总平衡式“等价”不成立。
- [问题] 问题四继承问题三的错误能源方程，联合优化的成本、碳排放、购售电和储能结果均会受到影响。
- [问题] 结构化问题二方程又出现 \(P^{dis}\) 和 \(P^{ch}\)，与正文“问题二不优化储能、充放电为零”及其变量清单不一致。
- [问题] 岭回归目标直接把非负截断 \(\max(0,\beta_0+\beta^\top z)\) 放入平方损失，却称为岭回归。应明确是先进行标准岭回归再对预测值截零，或明确采用相应的受约束/分段二次优化。
- [问题] 服务质量项 \(1-\overline W/W^{ref}\) 在等待时间超过参照值时会为负，与所声明的 \(Q_{\mathrm{service}}\in[0,1]\) 不一致，并可能错误影响 \(\epsilon_Q\) 约束。

### 量纲一致性
- [通过] GPU-hour、MW、MWh、成本和碳排放公式在显式采用 \(\Delta t=1\text{ h}\) 时量纲基本一致。
- [问题] \(L_{\mathrm{net}}\) 实际是 GPU-hour 加权平均时延，量纲为 ms，符号表中称“GPU-hour加权网络时延”容易被理解为未归一化总量，建议明确为“加权平均网络时延”。
- [通过] 多目标部分采用 ε 约束，避免了直接混合元、tCO2、ms 和 MW 等不同量纲。

### 约束完整性
- [通过] 已包含任务唯一执行、实时任务即时开工、到达与截止时间、2406 小时禁占用、网络时延、GPU、IT 功率和设施功率约束。
- [通过] 储能包含绝对初始 SOC、SOC 上下限、充放电效率、功率上限、充放电互斥及终端 SOC 约束。
- [问题] 能源守恒错误使问题二至问题四的约束系统不再代表真实物理系统，属于硬约束错误。
- [问题] 问题二应明确固定
  \[
  P^{ch}=P^{dis}=P^{RE,ch}=P^{grid,ch}=0,
  \]
  或从模型中彻底删除这些变量，不能在正文与结构化方程中采用不同口径。
- [问题] 问题三、四应明确采用附件中的 `MaxGridImport_MW`、`MaxGridExport_MW` 数值边界；目前仅以文字说明，规范模型中未完整列出。
- [问题] 服务质量指标需增加有限值和范围定义，例如对等待得分截断到 \([0,1]\)，否则其声明范围不成立。

### 参数合理性
- [通过] PUE、功率映射、时延、储能效率和容量均计划从附件读取，没有把未搜索的参数范围冒充文献证据。
- [通过] 模型没有声称已经获得拟合参数、RMSE、最优值或通过验证，符合 model 阶段边界。
- [问题] \(Q_{\mathrm{service}}\) 的权重仅称“公开”，但没有给出固定值或封闭生成规则。若该指标用于正式 ε 约束和折中选择，应在代码执行前预声明。
- [问题] 新能源波动情景的扰动幅度仍未给出固定值或封闭计算规则；正式求解前必须固定，不能依据结果反调。

### 可求解性
- [通过] 任务调度、储能互斥、峰值和绝对爬坡可构造成 MILP；零分母和不可行情景也给出了有限状态处理。
- [通过] 设置了共享 \(300\) 秒总预算、\(15\) 秒输出尾部预算及 \(285\) 秒搜索截止，没有分别向问题三和问题四重复分配完整预算。
- [问题] 能源方程修正前，即使求解器返回“可行”，也只是错误物理系统的可行解，不能作为正式结果。
- [问题] “已启动候选只有能在总截止前安全完成才保留”缺少可执行判据。应为每次求解设置不超过剩余搜索时间的明确 time limit，并在截止前停止启动新候选。
- [问题] 50000 个任务的全候选 MILP 规模可能很大；滚动窗口边界已有描述，但窗口长度、重叠长度和候选生成规则尚未封闭，属于实施风险。

### 数据可观测性
- [通过] 预测标签由实际到达任务聚合得到，真实可观测。
- [通过] 模型明确指出最优调度和最优储能动作不存在真实标签，未错误使用准确率、召回率或混淆矩阵。
- [通过] 对调度和储能采用约束残差、守恒复算、完成率、目标值和求解间隙作为验证指标，口径合理。
- [通过] WAPE 分母为零、累计新能源为零以及归一化分母为零时均设置了有限替代输出，未要求产生 NaN 或 Inf。

### 结果常识性
- [问题] 当前能源方程允许外送电量被重复记账，会形成非物理购售电和虚假收益，明显违反能量守恒常识。
- [通过] 储能禁止同时充放电，并对可能的交易套利设置业务规则核验。
- [通过] GPU、IT 功率、设施功率、网络时延、任务截止和储能终端状态均作为硬约束，未通过罚值放松现实边界。

## 修改建议
1. 问题二采用一套一致的能源方程。可使用
   \[
   U^{RE}+P^{sell}+P^{curt}=A^{RE},
   \qquad
   P^{buy}+U^{RE}=P^{fac},
   \]
   或直接使用
   \[
   P^{buy}+A^{RE}=P^{fac}+P^{sell}+P^{curt},
   \]
   但不能在分源平衡中再次加入已经由新能源守恒分配的 \(P^{sell}\)。

2. 问题三和问题四改为
   \[
   U^{RE}+P^{RE,ch}+P^{sell}+P^{curt}=A^{RE},
   \]
   \[
   P^{buy}+U^{RE}+P^{dis}
   =P^{fac}+P^{grid,ch},
   \]
   并保留
   \[
   P^{ch}=P^{RE,ch}+P^{grid,ch}.
   \]
   这与附件总平衡式
   \[
   P^{buy}+A^{RE}+P^{dis}
   =P^{fac}+P^{ch}+P^{sell}+P^{curt}
   \]
   等价。

3. 问题二删除储能变量，或显式固定所有充放电变量为零，使正文、结构化方程和变量清单完全一致。

4. 将预测模型明确为“标准岭回归拟合后截零”，或改写为确切的受约束回归模型及对应求解方法。

5. 将等待时间得分定义为
   \[
   \max\left\{0,1-\frac{\overline W}{W^{ref}}\right\},
   \]
   必要时同时截断上界，并预声明服务质量权重。

6. 在正式代码契约中固定滚动窗口参数、每次求解的剩余时间上限、情景扰动幅度以及所有购售电硬边界。
