# 模型验证报告

## 总体评价
需修改。任务调度、时间边界、GPU 重叠计量、SOC 递推、指标有限性和数据可观测性总体处理严谨，且没有把未执行的拟合或优化结果冒充为已验证结论。但问题三、问题四的新能源充电分源方程存在关键代数错误：式（28）与式（29）不能推出式（30），会将新能源充电功率重复计入能源需求。该错误同时传播到联合优化模型和验收残差，足以使成本、碳排放、储能策略及新能源利用率结论失效，必须阻断后续求解。

## 逐项检查

### 公式正确性
- [问题] 式（28）
  \[
  U+C^R+X^R+W=R
  \]
  与式（29）
  \[
  I+U+D=L^F+C^R+C^G
  \]
  合并后实际得到
  \[
  I+R+D=L^F+2C^R+C^G+X^R+W,
  \]
  而不是式（30）声称的
  \[
  I+R+D=L^F+C^R+C^G+X^R+W.
  \]
  新能源充电 \(C^R\) 被重复计入一次。
- [问题] 正确的分源口径应将新能源分配和负荷侧平衡分开。例如保留式（28），并把式（29）改为
  \[
  I+U+D=L^F+C^G.
  \]
  此时两式才能推出附件统一总平衡：
  \[
  I+R+D=L^F+C^R+C^G+X^R+W.
  \]
- [问题] 问题四明确复用问题三的式（28）—（38），因此上述错误直接传播至联合算—储—电模型。
- [问题] 验证式（61）采用的是正确的总平衡，但与当前原始决策方程（28）—（29）不一致。除非 \(C^R=0\)，模型方程和验收残差不能同时成立。
- [通过] 重叠函数式（1）正确处理半开执行区间，除以 \(\Delta t\) 后用于小时平均 GPU 和功率占用，公式与离散时域口径一致。
- [通过] SOC 递推中充电乘效率、放电除效率，初始状态和终端状态边界正确。
- [通过] 问题二的无储能分源方程 \(U+X^R+W=R\)、\(I+U=L^F\) 自洽，没有外送重复计量。
- [通过] WAPE、新能源利用率、空任务、零量程和无区分度指标均设置了有限输出分支，可避免 NaN/Inf。

### 量纲一致性
- [通过] \(H_{it}(s)\) 为 h，\(H_{it}(s)/\Delta t\) 无量纲；乘 GPU 需求得到等效 GPU 占用，乘 MW/GPU 得到 MW。
- [通过] 功率乘 \(\Delta t\) 后分别形成 MWh、电费和 tCO2，SOC 方程量纲一致。
- [通过] 网络时延、等待时间、利用率及归一化指标的量纲处理基本一致。
- [问题] 问题三、四能源式虽然各项单位均为 MW，但存在 \(C^R\) 的代数重复计量；量纲一致不能消除该守恒错误。

- [问题] 问题三和问题四当前数学方程与验收方程不一致。若求解器实施式（28）—（29），验收式（61）通常失败；若按式（30）实现，则代码又与正式模型定义不一致，因此尚不能形成唯一可靠的执行合同。
- [通过] 问题一为凸 Huber-岭回归加独立 MILP；问题二为线性分源滚动 MILP；修正能源方程后，问题三、四仍可表示为 MILP。
- [通过] 滚动窗口、冻结区、最晚开工保护、有限 ε 网格和预算停止规则均已明确，不依赖当前接口不提供的区间算法。
- [通过] 限时可行解与全局最优结论作了区分，并要求报告求解状态、间隙和约束残差。

- [通过] 禁止同时充放电、维持终端 SOC、限制购售电功率、限制 GPU 和设施容量等约束符合工程常识。
- [通过] 允许购电供负荷与新能源外送并存符合附件分源口径，不能仅因二者同时非零判定为套利。

## 修改建议
1. 保留式（28），将式（29）改为：
   \[
   I_{rt}+U_{rt}+D_{rt}=L_{rt}^{F}+C_{rt}^{G}.
   \]
2. 保留式（30）作为由修正后式（28）—（29）推出的总平衡。
3. 同步修改问题四引用的能源方程、结构化定义 `energy_q34` 及所有相关代码执行合同。
4. 修正后同时检查分源残差和总平衡残差，确保新能源充电只计量一次：
   \[
   U+C^R+X^R+W-R=0,
   \]
   \[
   I+U+D-L^F-C^G=0.
   \]
5. 在完成上述修正前，不应运行或解释问题三、问题四的成本、碳排放、新能源利用率、峰值和储能策略结果。
