# 模型验证报告

## 总体评价
需修改。任务重叠、功率映射、SOC 递推、终端约束、指标有限性和不可观测标签处理总体严谨，主要量纲也一致；但问题二滚动模型仍保留了未定义的新能源阈值约束，与“新能源利用率不进入 ε 约束”的正式口径直接冲突，导致模型没有唯一、可执行的约束集合。此外，净购电波动指标依赖可能松弛的辅助变量，尚未规定由最终序列复算，可能使问题三、四的比较结果失真。当前应判定为阻断性修改。

## 逐项检查

### 公式正确性
- [通过] 重叠时长式（1）正确，区间采用左闭右开形式，能够处理非整数小时的连续执行时长。
- [通过] GPU-hour 约束和式（6）除以 \(\Delta t\) 后得到小时平均 IT 功率，单位及附件口径一致。
- [通过] 储能分源平衡式（48）–（49）、（66）–（68）与 SOC 递推式（54）正确，充放电效率作用方向正确。
- [问题] 问题二正文式（45）要求
  \[
  A_U^{(j)}+\overline A_{U,rem}^{(j)}\ge\varepsilon_UW_U,
  \]
  但问题二没有定义或生成 \(\varepsilon_U\)，且前文、结构化模型均明确 \(U_{RE}\) 不进入 ε 约束。这使问题二存在两套相互冲突的约束定义。
- [问题] 波动指标 \(V\) 通过仅有下界的辅助变量 \(z_{rt}\) 定义。只有在最小化 \(V\) 时这些不等式才必然取紧；在成本、碳或峰值候选中，直接读取 \(\sum z_{rt}\) 可能大于真实绝对爬坡量。模型只对峰值规定了最终序列复算，没有对 \(V\) 作同样处理。
- [问题] 问题一声称增强预测模型需达到“预声明选择规则”才替代季节性基线，但现有字典序只用于选择增强模型的超参数，未定义增强模型与两个季节性基线之间的唯一比较规则。

### 量纲一致性
- [通过] 等待时间项 \(\alpha_k(s-a_i)\) 和时延项 \(\beta_k\ell_{o_ir}\) 均无量纲。
- [通过] \(g_i\omega_{it}\) 为 GPU·h，除以 \(\Delta t\) 后与 GPU 容量及 MW 功率映射一致。
- [通过] 功率乘一小时得到 MWh，购电功率乘碳强度和时间得到 tCO2，购售电成本单位为元。
- [通过] SOC、循环量、时延加权均值及服务质量代理的量纲一致。

### 约束完整性
- [通过] 已包含任务唯一执行、不可抢占、到达时间、完成期限、实时任务即时开工、网络时延、GPU、IT 功率、设施功率及第 2406 小时禁占用约束。
- [通过] 问题三、四包含 SOC 初值、上下限、功率、效率、充放电互斥和终端 SOC 约束。
- [通过] 问题二不读取仅适用于问题三、四的储能表字段，符合给出的原始附件字段证据。
- [问题] 问题二式（45）必须删除，或者重新将新能源阈值正式定义为问题二目标并同步修改所有文字、变量、ε 网格和输出契约；不能同时保留两种口径。
- [问题] q3/q4 应明确正式波动值为
  \[
  \widehat V=\sum_r\sum_{t=1}^{2406}|N_{rt}-N_{r,t-1}|,
  \]
  并规定比较、绘图、变化率、Pareto 指标和文件输出只能使用 \(\widehat V\)。
- [通过] 同时购电与新能源外送已要求单独披露，且没有错误称为协同效率提升。

### 参数合理性
- [通过] 预测超参数集合、时间窗口 \(H=168\)、重叠区 \(O=24\)、提交长度 \(F=144\) 均为固定、有限且可复现的规则。
- [通过] 共享预算采用 \(B_{total}=300\) s、\(T_{tail}=15\) s 和 \(D_{search}=t_{start}+285\) s，符合给定运行环境的封闭缺省口径。
- [通过] 未把尚未搜索的调研内容伪装成文献事实，也没有在 model 阶段声称已获得拟合参数、误差或最优数值。
- [问题] 新能源压力测试中的 \(\mu_\xi,\sigma_\xi\) 尚待代码阶段预声明，当前作为 pending 参数可以接受，但不得在看到优化结果后调整。

### 可求解性
- [问题] 问题二式（45）使用未定义的 \(\varepsilon_U\)，使直接照公式构建模型时无法确定约束右端；这是当前的主要阻断项。
- [通过] 除上述冲突外，各子问题均可表达为 MILP 或有限候选 MILP，并提供了限时停止、完整可行 incumbent、全时域复核和结构化不可行输出。
- [通过] 未把区间 ODE、Interval Newton 或连续域形式化证书设为硬要求。
- [问题] “首次生成覆盖全部任务与能源状态的完整可行 incumbent”应允许输出结构化不可行状态；不能把无法生成 incumbent 的情况解释为算法已完成正式求解。
- [问题] 在共享 300 秒预算内，问题一固定工作、三个问题基准、多个锚点和候选均竞争同一预算。现有启动检查总体正确，但最终实现必须在每项固定工作前也检查尾部预留，不能只对 ε 候选检查截止时间。

### 数据可观测性
- [通过] 需求标签可由实际到达任务聚合，预测 MAE、RMSE、WAPE 均有真实测试标签。
- [通过] 最优调度、储能动作和用户满意度被正确识别为不可观测，没有使用准确率、召回率或混淆矩阵验证优化结果。
- [通过] \(Q_{service}\) 被明确称为等待时间代理，而非真实用户满意度。
- [通过] 对 WAPE、相关系数、自相关、\(W_L\)、\(W_U\)、\(M_W\) 和循环量分母设置了可计算性门禁，可避免正常分支产生 NaN 或 Inf。
- [通过] 未执行外部搜索的状态披露真实，没有引用不存在的外部证据。

### 结果常识性
- [通过] 模型包含 GPU、IT 功率、设施功率、时延、截止时间、购售电、储能功率和 SOC 等主要现实边界。
- [通过] 禁止同时充放电，避免非物理储能循环。
- [通过] 对问题二无独立外送容量造成新能源利用率退化为 100% 的现象作了明确披露，并改报直用、外送和弃电分流指标。
- [问题] 允许购电供负荷同时外送本地新能源虽符合当前分源方程，但可能产生反常经济结果；现有单独统计和价格机制披露要求必须保留，不能将其表述为新能源直接消纳改善。

## 修改建议
1. 删除问题二滚动契约中的式（45）及相应 \(\varepsilon_U\) 表述，保留 \(A_U^{(j)}\) 仅用于分流诊断和最终守恒复算；同时将“式（39）、（42）、（45）分别防止……”改为只引用式（39）和式（42）。
2. 新增正式波动复算指标
   \[
   \widehat V=\sum_r\sum_{t=1}^{2406}|(B_{rt}-S_{rt})-(B_{r,t-1}-S_{r,t-1})|,
   \]
   明确 \(z_{rt}\) 和 \(V\) 只用于优化约束，所有报告、基准比较和 Pareto 数据使用 \(\widehat V\)。
3. 为增强预测与季节性基线增加唯一选型规则，例如按验证集总体 WAPE、MAE、模型复杂度的预声明字典序比较；WAPE 不可计算时从 MAE 开始。
4. 在实现中对全部阶段统一执行墙钟检查，并在无法生成完整可行 incumbent 时输出明确的不可行或预算耗尽状态，不得把未完成搜索报告为已验证方案。
