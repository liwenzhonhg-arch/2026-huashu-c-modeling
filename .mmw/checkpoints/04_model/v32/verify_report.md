# 模型验证报告

## 总体评价
需修改。模型的任务时域、不可抢占约束、功率映射、储能 SOC 递推、终端状态、可观测性和有限输出处理总体严谨，也没有把未执行的拟合或外部调研冒充既得结果。但问题二的能源平衡重复计入新能源外送，允许通过额外购电“支撑”新能源售电，直接导致成本、碳排放和新能源利用率失真；问题一末端调度也未明确纳入第 2376 小时前已开工但仍在运行的任务占用。这两项会使对应调度结论失效，当前严重程度为 `block`。

## 逐项检查

### 公式正确性
- [问题] 问题二同时给出
  \[
  G_{rt}^{buy}+R_{rt}^{use}=L_{rt}^{F}+G_{rt}^{sell}
  \]
  和
  \[
  R_{rt}^{use}+R_{rt}^{sell}+R_{rt}^{curt}=R_{rt}^{av},\qquad
  G_{rt}^{sell}=R_{rt}^{sell}.
  \]
  这里 \(R^{sell}\) 已经在新能源分源守恒中从 \(R^{av}\) 分配出来，却又被放到负荷侧平衡右端，等价于要求额外购电来补偿新能源外送。正确的分源形式应为
  \[
  G_{rt}^{buy}+R_{rt}^{use}=L_{rt}^{F},
  \]
  再单独使用新能源分源守恒和 \(G^{sell}=R^{sell}\)；或者统一写成
  \[
  G_{rt}^{buy}+R_{rt}^{av}
  =L_{rt}^{F}+G_{rt}^{sell}+R_{rt}^{curt}.
  \]
- [问题] 问题二结构化方程仅列出 \(R^{use}\)，没有完整保留正文中的 \(R^{sell}\)、\(R^{curt}\) 变量及新能源分源守恒。若 Coder 按结构化方程实现，将无法正确输出新能源外送和弃电策略。
- [通过] 小时重叠系数正确表示任务执行区间与小时区间的交集长度；由于小时长度为 1，其数值同时也是小时占用比例。
- [通过] AI IT 负荷、总 IT 负荷和设施负荷之间的映射符合附件统一口径。
- [通过] 问题三的分源方程、负荷侧平衡、总购电分解和总能量平衡彼此等价，未重复计算新能源充电。
- [通过] SOC 递推中充电乘效率、放电除效率，方向和符号正确。
- [通过] 碳排放、运行成本、网络时延和等效循环量公式量纲与题目口径一致。
- [问题] 问题一词典序目标中的 \(U^{\max}\) 只作文字说明，没有显式给出
  \[
  U^{\max}\ge
  \frac{\sum_{i,s}g_i\omega_{it}(s)x_{irs}}{G_r^{\max}},
  \quad\forall r,t.
  \]
  缺少这些线性约束时，第三层目标在数学模型中没有被真正绑定。

### 量纲一致性
- [通过] \(g_i\omega_{it}\) 在每个一小时时段内对应等效 GPU-hour；按附件指定的折算口径，可与逐时可调度 GPU 容量对应比较。
- [通过] \(g_ip_k^{GPU}\omega_{it}\) 的单位为 MW，能够与 NonAI IT 负荷及 IT 功率上限相加或比较。
- [通过] 功率乘一小时得到 MWh；再乘元/MWh或 tCO2/MWh，分别得到元和 tCO2。
- [通过] SOC 方程各项均为 MWh，网络时延加权平均保持 ms，爬坡总量 \(V_r\) 按当前定义为逐小时功率差绝对值之和，单位为 MW。
- [问题] \(d_i\) 在符号表中称为“连续运行时长”，但后续始终使用 \(d_i/60\)，说明其实际单位应明确写成 min，避免被误读为小时。

### 约束完整性
- [问题] 问题一只说明对第 2376–2399 小时实际到达任务生成候选并求解，没有明确把第 2376 小时前已开工且延续到该区间的任务作为固定占用，或先对此前任务形成完整基础调度。若存在跨越 2376 的既有任务，末端 MILP 的 GPU、IT 功率和设施功率约束会低估真实占用。
- [通过] 每个任务唯一执行、到达后开工、实时任务即时开工、网络时延、截止时间及第 2406 小时禁占用约束均已建立。
- [通过] GPU、IT 功率和设施功率三层容量约束均被保留。
- [通过] 问题三和问题四包含 SOC 上下限、充放电功率、效率、终端 SOC、购售电边界以及充放电互斥。
- [通过] 滚动窗口要求传递跨窗口任务占用和绝对 SOC，避免任务中断或状态重置。
- [问题] 售电业务口径已由附件说明为新能源富余外送，模型仍把“同通道互斥”作为待核验候选。可以进行敏感性对照，但正式主模型应直接采用附件给出的新能源分源口径，不应因未额外核验而阻断输出。
- [问题] 问题四服务质量由计数比值和等待时间比值构成。虽然可在线性模型中转化为常数分母下的线性表达，但模型应明确固定权重满足 \(w_j\ge0,\sum_jw_j=1\)，并预声明无定义分量删除后的确定性重归一化规则。

### 参数合理性
- [通过] PUE、效率、SOC、功率和网络时延均作为附件输入，没有虚构所谓典型范围。
- [通过] 外部搜索明确标记为未执行，未把未搜索的参数范围当作文献事实。
- [通过] 模型阶段没有声称已经得到拟合参数、RMSE、\(R^2\)、最优调度或通过验证。
- [问题] 问题四的多目标权重 \(w_j\)、服务质量权重 \(w_1,\ldots,w_4\)、ε 网格及情景幅度尚未给出固定生成规则。它们可以留待代码阶段产生具体数值，但必须在求解前预声明，不能根据结果方向事后调整。
- [问题] 新能源波动的正文公式为
  \[
  \max(0,R^{av}+\sigma_{sc}\xi),
  \]
  结构化版本却写成
  \[
  \max(0,\delta_RR^{av}+\xi^{sc}).
  \]
  两者对扰动幅度的参数化不一致，应统一。

### 可求解性
- [通过] 任务候选离散化后，问题一和问题二可建成 MILP；问题三、问题四加入运行互斥后二元变量虽多，但模型类型明确。
- [通过] 300 秒共享预算、285 秒搜索截止和15秒输出审计预留符合单轮可执行预算要求，没有把完整预算分别赋给多个子问题。
- [通过] 滚动时域方案包含跨窗口状态传递、全时域复核和限时解状态披露，原则上可执行。
- [问题] 问题二必须先修正能源平衡，否则求解器即使返回“最优解”，也只是错误物理模型的最优解。
- [问题] “若滚动拼接失败则扩大窗口或改用一次性整体 MILP”缺少受共享截止约束的具体选择规则。应在启动前依据剩余时间选择预声明的有限窗口集合，不能在失败后无界扩大。
- [通过] 常数序列相关系数、零新能源分母、零 WAPE 分母和 Pareto 归一化零分母均设置了有限替代输出，不会产生 NaN 或 Inf。

### 数据可观测性
- [通过] 预测标签由实际任务表聚合得到，MAE、RMSE 和 WAPE 均有真实可观测对象。
- [通过] 调度与储能没有真实最优标签，模型没有错误使用准确率、召回率或混淆矩阵。
- [通过] 对不可观测的最优策略采用约束残差、守恒复算、求解状态、最优间隙和基准变化等代理验证，口径合理。
- [通过] 附件基准 SOC 被正确视为对比轨迹，而非优化标签或固定约束。
- [通过] 常数序列相关系数明确标记为不可用，没有把不可计算或负相关指标解释为验证有效。

### 结果常识性
- [问题] 问题二错误的能源平衡会产生“购电增加，同时新能源外送”的人工循环，并可能在售电价格较高时形成虚假套利，违反能源流常识。
- [通过] 模型包含 GPU、IT 功率、设施功率、网络时延、任务截止、储能容量、充放电功率和购售电上限等现实约束。
- [通过] 同时充放电被禁止；购电与新能源外送是否并存则按分源物理口径处理，没有简单地把所有同时购售电都判为违规。
- [通过] 问题三固定题面指定的基准 AI IT 负荷与 NonAI IT 负荷，没有越权重新调度任务。
- [通过] 最后24小时正式调度明确使用实际到达任务，而非预测值。

## 修改建议
1. 修正问题二能源系统，建议采用：
   \[
   R^{use}+R^{sell}+R^{curt}=R^{av},
   \]
   \[
   G^{buy}+R^{use}=L^F,
   \]
   \[
   G^{sell}=R^{sell},
   \]
   并保留购电、售电上限。随后同步修改结构化方程、变量清单和审计残差。
2. 问题一末端调度应先形成第0–2375小时基础调度，或把第2376小时前已启动且尚未结束的任务占用作为固定参数加入2376–2405小时容量约束。
3. 为 \(U^{\max}\) 补充逐区域逐时的显式上界约束，并明确利用率使用比例值还是百分数值。
4. 将 \(d_i\) 的单位明确为 min；统一正文与结构化模型中的新能源波动公式。
5. 固定服务质量权重、理想点距离权重、ε 网格和有限滚动窗口集合的生成规则；具体数值可以在代码阶段按预声明规则计算。
6. 正式主模型按附件采用新能源分源外送口径；“同通道互斥”只可作为额外敏感性候选，不应成为停止正式求解的前置条件。
