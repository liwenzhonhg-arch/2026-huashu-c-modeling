# 模型验证报告

## 总体评价
需修改。任务不可抢占、分钟重叠计量、功率映射、储能 SOC、终端状态及可观测性口径总体合理，也没有虚构拟合参数或使用不可观测的分类标签；但当前模型存在会影响正式求解的边界错误与有限输出缺口：问题二错误引用仅供问题三、四使用的储能外送参数压缩购售电边界，网络时延等指标缺少零分母处理，预测模型中的周期特征 \(z_t\) 未定义，导致实现不唯一。前两项会使部分合法输入下的结论失效，应在代码求解前修正。

## 逐项检查

### 公式正确性
- [通过] 重叠时长 \(\omega_{it}(s)\)、占用指示 \(\chi_{it}(s)\)、AI IT 电量、PUE 换算、SOC 递推、成本及购电碳排放公式与题面口径一致。
- [通过] \(P_r^{peak}\ge0\) 并按 \(\max\{0,\max_tN_{rt}\}\) 复算，避免全时域净外送时得到负的“峰值购电功率”。
- [问题] 式(46)的 \(L_{\mathrm{net}}\) 未处理 \(\sum_i g_ih_i=0\)；空任务集、零 GPU 任务集或零持续时间数据会产生 NaN/Inf。该指标又进入问题二、四的锚点、约束和候选排序，可能使整个优化路径失效。
- [问题] 式(73)–(75)先定义了可能为 \(0/0\) 的 \(Q_{\mathrm{RT}}\)、\(Q_{\mathrm{SLA}}\)、\(Q_{\mathrm{deadline}}\) 和 \(Q_{\mathrm{wait}}\)，之后才规定只将正分母分量纳入 \(J_{\mathrm{def}}\)。实现必须先检查分母再计算分量，不能先生成 NaN 后再筛选。
- [问题] Huber 模型把截断预测 \(\max\{0,\cdot\}\) 直接放入损失，已不再是标准线性 Huber 回归目标；模型没有说明采用何种可复现算法求解这一分段非光滑问题。若实际计划使用标准 Huber 回归后再截零，应把训练目标和预测后处理分开表述。

### 量纲一致性
- [通过] GPU、GPU-hour、MW、MWh、小时重叠、成本和碳排放的主要等式量纲一致。
- [通过] \(g_ip_k^{GPU}\omega_{it}\) 的量纲为 MWh，除以 \(\Delta t\) 后为 MW；SOC 递推中功率乘时段长度后为 MWh。
- [通过] 网络时延采用 GPU-hour 加权，式(46)结果为 ms；新能源利用率和服务质量均为无量纲。
- [问题] 式(28)中的常数下限应在实现中明确为数值 \(1\) 且单位为等效 GPU，不能把带单位文本直接送入数值运算；这属于实现说明问题。

### 约束完整性
- [通过] 唯一执行、到达后开工、实时任务即时开工、截止时间、单向网络时延、GPU容量、IT功率、设施功率和第2406小时禁占用均已覆盖。
- [通过] 问题三固定题面指定负荷，没有重新调度任务；储能初始 SOC、上下限、效率、功率、互斥及终端 SOC 约束完整。
- [问题] 式(14)在全部子问题中统一采用 \(E_r^{\max}=\min\{X_r^{grid},X_r^{storage}\}\)。但题面明确 `storage_information.xlsx` 仅用于问题三、四，问题二的无储能模型不应引用储能附件中的 `SellLimit_MW` 来限制新能源外送。问题二应直接使用其适用的区域级 `MaxGridExport_MW`；问题三、四只有在数据字典能够证明两个上限同时约束同一外送流时才可取最小值。
- [问题] 符号 \(X_r^{storage}\) 被解释为“储能外送边界”，但详细能源方程只允许 \(D_{rt}\) 服务本地负荷，未建立储能向外送电的流量。若 `SellLimit_MW` 实际是区域总外送上限，应更名并明确其作用对象；若确为储能外送上限，则当前取最小值约束全部新能源外送没有物理依据。
- [通过] 问题一前序占用集合虽然命名为“跨界占用”，其条件 \(a_i<2376,\ s_i^0+h_i>2376\) 实际也包含2376以后才开工的前序弹性任务，因此能够计入末端容量，并未遗漏这些任务。
- [问题] 滚动窗口只给出了任务集合和候选域更新规则，没有明确每个窗口的能源时段范围、窗口末端状态传递方式，以及窗口内哪些开工决定在何时正式提交。现有“仅提交已开工任务”文字不足以唯一重建拼接算法，需在代码契约中封闭定义。

### 参数合理性
- [通过] 任务、电价、碳强度、PUE、功率映射和储能参数均声明从附件读取，没有把未搜索的“典型范围”伪装成文献事实。
- [通过] 当前阶段没有声称已经获得回归系数、RMSE、锚点或最优值，符合模型阶段边界。
- [通过] 300秒总预算、15秒终检预留和动态单次硬时限均给出固定数值和封闭计算规则。
- [问题] 式(24)中的周期特征向量 \(z_t\) 没有定义组成、编码、缩放及维度。该未定义参数会使预测模型不可复现，也无法核查设计矩阵是否仍存在共线性。
- [问题] 新能源波动情景仅通过截零处理负出力。截零后样本均值和方差不再保持式(92)扰动前设定值；应把它描述为明确的截断情景生成规则，不能再声称最终扰动仍具有零均值和指定方差。

### 可求解性
- [通过] 在候选集合有限时，任务分配、容量、能源流、储能和互斥主体可构造成 MILP；滚动求解结果也明确只声明 `best-found`，不冒充全局最优。
- [通过] 贪心失败后改用完整可行性 MILP，并区分 `infeasible` 与 `feasibility_unresolved`，逻辑正确。
- [通过] 所有优化子问题共享同一300秒墙钟预算，并为输出和终检预留15秒；后序问题允许诚实停止。
- [问题] 非光滑截断 Huber 目标及未定义的 \(z_t\) 使预测部分尚不能按当前公式唯一实现。
- [问题] 问题二、三、四需要大量基准、单目标锚点、滚动窗口和情景 MILP。模型允许预算耗尽后停止，因此不构成独立错误，但必须预先给出每个必答结果的 `pending_code_execution`、`timeout` 或 `not_run_budget_exhausted` 状态，避免将缺失结果误写为正式策略。

### 数据可观测性
- [通过] 预测标签来自实际 GPU/GPU-hour 到达需求；MAE、RMSE、WAPE均可由测试期真实到达数据计算。
- [通过] 没有将不可观测的全局最优调度当作真实标签，也没有错误使用准确率、召回率或混淆矩阵。
- [通过] 成本、碳排放、等待时间、网络时延、能源流、SOC、新能源利用率及峰值均可由附件和决策轨迹复算。
- [问题] 当分组真实需求总和为零时，WAPE 应逐组标记不可计算；“保留总体WAPE”只有在总体分母严格为正时才合法。
- [问题] 服务质量中的即时开工率、SLA达标率和截止达标率在硬约束完全执行时恒为1，不能作为区分可行候选优劣的有效信息。可以保留为合规审计项，但折中优化中实际有辨别力的主要是等待指标。

### 结果常识性
- [通过] 禁止同时充放电、限制同时购售电、使用非负购电峰值、固定非AI负荷并限制设施容量，符合工程常识。
- [通过] 实时任务即时开工，弹性任务受截止时间约束，且所有任务不得占用2406小时。
- [问题] 问题二将储能附件的外送限制施加于无储能调度，可能无依据地压低新能源外送和利用率，进而扭曲成本、碳排和迁移策略。
- [问题] 若滚动窗口没有明确传递 SOC 和已发生能源动作，后续窗口可能重新使用已经消耗的储能能量；必须将窗口起点 SOC 和历史已提交能源流固定下来。

## 修改建议
1. 将问题二的外送上限改为题面适用的区域级 `MaxGridExport_MW`。问题三、四分别核对 `MaxGridExport_MW` 与 `SellLimit_MW` 的数据字典含义，只有二者确实同时约束同一物理外送流时才使用最小值。
2. 对 \(L_{\mathrm{net}}\) 及所有服务质量分量实行“先验分母门禁”：分母不正时不执行除法，输出有限状态并排除对应锚点、约束和排序维度。
3. 完整定义 \(z_t\)，例如明确小时、星期周期的正余弦或独热编码、基准列、缩放方式和最终维度。
4. 明确 Huber 的实现口径：建议用未截断线性预测拟合凸 Huber 目标，拟合完成后再用 \(\max(0,\widehat D)\) 生成非负预测；若坚持在目标内截断，则需指定可执行的分段优化算法及终止规则。
5. 补全滚动窗口契约：规定窗口覆盖时段、允许观察的任务、提交区间、窗口末端 SOC、已发生购售电和储能动作的固定方式，以及最后一个窗口到2406的结清规则。
6. 将恒为1的实时开工、SLA和截止指标主要作为硬约束审计输出；折中服务质量应明确由仍有变化的等待或其他题内可观测量驱动。
