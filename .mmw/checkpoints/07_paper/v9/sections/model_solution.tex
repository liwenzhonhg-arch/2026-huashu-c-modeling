\section{模型的建立与求解}

\subsection{数据预处理与统一计量口径}

工作负载、GPU 中心、网络时延、功率映射、区域逐时数据与储能信息首先被按字段说明进行一致性核验。工作负载共包含 $50000$ 条输入任务记录，均通过数据完整性校验，缺失单元格数量为 $0$。区域、任务类型和小时索引被统一编码，任务类型与单位等效 GPU 功率按照功率映射表连接，区域间通信采用有向单向时延矩阵。逐时电力数据覆盖任务主时域、末端结清时域和终端结算时点，其中第 $2406$ 小时不得安排任务，仅用于能源与储能状态结算。

任务 $i$ 的持续小时数及有效截止时点被定义为
\begin{equation}
h_i=\frac{d_i}{60},\qquad F_i=\min\{f_i^{\mathrm{valid}},2406\}.
\label{eq:duration_deadline}
\end{equation}
若任务在整数时刻 $s$ 开工，则其与小时区间 $[t,t+1)$ 的实际重叠时长和瞬时占用指示量分别为
\begin{align}
\omega_{it}(s)&=\max\{0,\min(t+1,s+h_i)-\max(t,s)\},\\
\chi_{it}(s)&=\mathbf 1\{\omega_{it}(s)>0\}.
\end{align}
其中，$\omega_{it}(s)$ 被用于 GPU-hour 和电量计算，$\chi_{it}(s)$ 被用于 GPU、IT 功率与设施功率的瞬时容量审计。

系统成本、购电碳排放、有效网络时延和新能源利用率统一按
\begin{align}
C_{\mathrm{op}}
&=\sum_{r,t}\left(c_{rt}^{buy}G_{rt}^{buy}
-c_{rt}^{sell}G_{rt}^{sell}\right)\Delta t,\\
E_{\mathrm{CO2}}
&=\sum_{r,t}\kappa_{rt}G_{rt}^{buy}\Delta t,\\
L_{\mathrm{net}}
&=\frac{\sum_i g_ih_i\ell_{o_ir_i}}{\sum_i g_ih_i},\\
U_{\mathrm{RE}}
&=\frac{\sum_{r,t}(R_{rt}^{use}+R_{rt}^{ch}+R_{rt}^{sell})\Delta t}
{\sum_{r,t}R_{rt}^{av}\Delta t}
\end{align}
复算。网络时延和新能源利用率仅在分母为正时计算，否则相应指标被标记为不可用并退出评分。多目标候选只有通过全部硬约束后才参与比较，其指标差异采用有限正中位绝对尺度标准化\cite{huber1964robust,miettinen1999nonlinear}。

% MMW-ALGORITHM: 固定Huber滞后回归；50000任务确定性贪心可行构造；问题二从4个优先任务构造邻域并最多完整评价4个候选；问题三评价基准及12组规则型储能策略；问题四复用同类单任务邻域构造一个与基线不同的替代任务方案，对替代方案执行一次50000任务全量硬约束审计，形成两个任务候选的统一集合；15个情景分别对两个任务候选重建设施负荷和情景储能策略，完整审计能源、SOC、互斥和购售电边界后选择实际检查集合中的best-found；全部搜索受270秒主动截止、285秒合同硬截止和300秒总截止约束。

实际程序采用 Python 与 scikit-learn 实现。需求预测采用固定 Huber 滞后回归，基础任务调度采用 NumPy 区间切片支持的确定性贪心构造，能源流根据真实调度形成的小时电量重新计算。问题二对有限单任务邻域作全量复算，问题三搜索有限规则型 SOC 候选；问题四对统一的两个任务方案逐情景重建设施负荷和储能策略。除新能源波动情景采用固定随机种子 $2026$ 外，其余过程均为确定性构造。

由表~\ref{tab:q1_group_statistics} 可见，各区域的任务组成存在明显差异，因而预测模型需要同时保留区域效应与任务类型效应。RegionD、RegionE 和 RegionF 的 AITraining 任务对应较大的 GPU 需求与 GPU-hour，而 RegionA、RegionB 和 RegionC 的 RealTimeInference 任务数相对较多。任务数、GPU 需求与 GPU-hour 所刻画的侧重点并不相同，因此调度容量不能仅依据任务数量判断，仍须结合持续时间和逐时重叠关系进行审计。

预测模型引入短期、日内和周内滞后项，并采用
\begin{equation}
z_t=\left[
\sin\frac{2\pi t}{24},
\cos\frac{2\pi t}{24},
\sin\frac{2\pi t}{168},
\cos\frac{2\pi t}{168}
\right]^{\mathsf T}
\end{equation}
表示周期特征。未截断预测量为
\begin{equation}
u_{rkt}=\beta_0+
\sum_{\ell\in\{1,2,3,24,48,168\}}\beta_\ell D'_{rk,t-\ell}
+\gamma^{\mathsf T}z_t+\alpha_r+\delta_k,
\end{equation}
最终预测结果取
\begin{equation}
\widehat D_{rkt}=\max\{0,u_{rkt}\}.
\end{equation}

% MMW-ID: CON-Q1-6
预测误差采用
\begin{align}
\mathrm{MAE}&=\frac{1}{n}\sum_j|y_j-\widehat y_j|,\\
\mathrm{RMSE}&=\sqrt{\frac{1}{n}\sum_j(y_j-\widehat y_j)^2}
\end{align}
评价，WAPE 仅在真实值绝对和为正时计算。最终测试的总体 MAE 为 $24.9733$ GPU，总体 RMSE 为 $35.6945$ GPU；测试区间形成 $432$ 条区域—任务类型逐小时预测记录，需求统计明细形成 $43200$ 行结果。

% MMW-LIMITATION: D2
方法契约原计划比较季节性基线并执行完整超参数网格，但实际运行采用固定的 $\epsilon=1.35$ 和 $\alpha=0.001$，未完成全部候选的验证选模。因此，现有误差仅反映已实现固定模型在保留测试区间上的表现。

\subsubsection{任务候选域与容量约束}

% MMW-ID: CON-Q1-1
任务 $i$ 的合法执行区域—开工时刻集合为
\begin{equation}
\Omega_i=\left\{(r,s):s\ge a_i,\ s+h_i\le F_i,\
\ell_{o_ir}\le\ell_i^{\max},\ \omega_{i,2406}(s)=0\right\}.
\end{equation}
若 $\Omega_i$ 为空，则任务及排除原因被记录，构造过程返回结构化状态。

% MMW-ID: CON-Q1-2
每个任务必须且只能选择一个候选，实时推理任务必须在到达时刻开工：
\begin{align}
\sum_{(r,s)\in\Omega_i}x_{irs}&=1,\\
s_i&=\sum_{(r,s)\in\Omega_i}sx_{irs},\qquad c_i=s_i+h_i,\\
s_i&=a_i,\qquad i\in\mathcal I_{\mathrm{RT}}.
\end{align}

% MMW-ID: CON-Q1-3
区域逐时 GPU、IT 功率和设施功率满足
\begin{align}
\sum_{i,s}g_i\chi_{it}(s)x_{irs}&\le G_r^{\max},\\
L_{rt}^{N}+\sum_{i,s}g_ip_{k_i}^{GPU}\chi_{it}(s)x_{irs}
&\le P_r^{IT,\max},\\
\pi_r\left(L_{rt}^{N}+\sum_{i,s}g_ip_{k_i}^{GPU}
\chi_{it}(s)x_{irs}\right)&\le P_r^{F,\max}.
\end{align}

% MMW-ID: CON-Q1-4
能源结算采用实际重叠时长：
\begin{align}
E_{rt}^{AI}&=\sum_{i,s}g_ip_{k_i}^{GPU}\omega_{it}(s)x_{irs},\\
L_{rt}^{AI,avg}&=\frac{E_{rt}^{AI}}{\Delta t},\\
L_{rt}^{F,avg}&=\pi_r(L_{rt}^{N}+L_{rt}^{AI,avg}).
\end{align}

% MMW-ID: CON-Q1-5
区域逐时峰值利用率和 GPU-hour 平均利用率分别为
\begin{align}
U_{rt}^{peak}
&=\frac{\sum_{i,s}g_i\chi_{it}(s)x_{irs}}{G_r^{\max}},\\
U_{rt}^{avg}
&=\frac{\sum_{i,s}g_i\omega_{it}(s)x_{irs}}
{G_r^{\max}\Delta t}.
\end{align}
两项指标仅在 $G_r^{\max}>0$ 时计算。最后 $24$ 小时的区域 GPU 利用情况见图~\ref{fig:gpu_utilization}。

\subsection{统一多指标方向与实际决策规则}

对任一满足硬约束的候选 $x$，理论评价向量统一写为
\begin{equation}
\mathbf f(x)=\bigl(C(x),E(x),L(x),1-Q(x),1-U(x),P(x),V(x),M(x)\bigr),
\end{equation}
其中 $C,E,L,P,V,M$ 分别表示运行成本、碳排放、有效网络时延、非负峰值净购电、绝对爬坡量和迁移数，$Q,U$ 分别表示服务质量与新能源利用率。上述各分量均按最小化方向解释；两个候选之间采用 Pareto 支配关系，不预设主观权重。

实际程序只形成有限候选集：问题二完整复算 $4$ 个单任务候选，问题三审计 $13$ 个规则型储能候选，问题四在每个情景比较同一组 $2$ 个任务方案并重建对应储能策略。实际决策规则是“先通过全部硬约束审计，再在实际检查集合中保留代理评分 best-found；审计失败或构造未完成则不输出正式候选”。这些有限候选不足以形成可信 Pareto 前沿，故结果仍只能称为多指标评价下的场景可行候选，而不是加权和最优解、Pareto 前沿或全局最优解。

\subsection{问题二：无储能碳感知任务调度}

% MMW-ID: OBJ-Q2
问题二从问题一的可行任务方案出发，以单任务迁移或开工时刻变更构造有限邻域，并对成本、碳排放、有效网络时延和等待量进行尺度化比较。实际程序从 $4$ 个优先任务中形成候选，完整复算并审计 $4$ 个候选；接受改进数为 $0$，状态为 \texttt{searched\_no\_improvement}。该状态只表示实际检查集合中未发现严格改善。

% MMW-ID: CON-Q2-1
全部 $50000$ 个实际任务均执行唯一选址、实时即时开工、到达与截止、单向时延、瞬时 GPU、IT 功率、设施功率和真实重叠电量约束，预测需求不替代真实任务。

% MMW-ID: CON-Q2-2
问题二不配置储能，故
\begin{equation}
R_{rt}^{ch}=G_{rt}^{ch}=C_{rt}=D_{rt}=0,
\end{equation}
并满足
\begin{align}
R_{rt}^{use}+R_{rt}^{sell}+R_{rt}^{curt}&=R_{rt}^{av},\\
G_{rt}^{buy}+R_{rt}^{use}&=L_{rt}^{F,avg},\\
G_{rt}^{sell}&=R_{rt}^{sell}.
\end{align}

% MMW-ID: CON-Q2-3
购售电边界满足
\begin{align}
0\le G_{rt}^{buy}&\le I_r^{\max}y_{rt}^{grid},\\
0\le G_{rt}^{sell}&\le X_r^{grid}(1-y_{rt}^{grid}),
\qquad y_{rt}^{grid}\in\{0,1\}.
\end{align}
问题二不读取储能售电限制或 SOC 字段。

% MMW-ID: CON-Q2-4
新能源优先分流规则为
\begin{align}
R_{rt}^{use}&=\min\{R_{rt}^{av},L_{rt}^{F,avg}\},\\
G_{rt}^{buy}&=L_{rt}^{F,avg}-R_{rt}^{use}.
\end{align}
新能源富余时，外送量受 $X_r^{grid}$ 限制，其余部分被计为弃电。

% MMW-ID: CON-Q2-5
问题二运行成本为 $-419658147.7076$ 元，碳排放为 $14.3916$ tCO$_2$。全时域累计购电为 $40.4664$ MWh，累计售电为 $1329591.2956$ MWh。由于成本量纲为购电支出减售电收入，负值表示在给定售电价格及外送边界下累计售电收入超过购电支出，并不表示发电成本为负。

\subsection{问题三：固定负荷下的储能协同模型}

% MMW-ID: OBJ-Q3
问题三固定采用基准 AI IT 负荷和非 AI IT 负荷，并在理论模型中评价成本、碳排放、非负峰值净购电、绝对爬坡及有效新能源未利用率。无储能状态只作为比较对象，不作为含储能构造的启动判据。

% MMW-ID: CON-Q3-1
区域设施负荷及能源流满足
\begin{align}
L_{rt}^{F,avg}&=\pi_r(L_{rt}^{BAI}+L_{rt}^{N}),\\
R_{rt}^{use}+R_{rt}^{ch}+R_{rt}^{sell}+R_{rt}^{curt}&=R_{rt}^{av},\\
G_{rt}^{load}+R_{rt}^{use}+D_{rt}&=L_{rt}^{F,avg},\\
C_{rt}&=R_{rt}^{ch}+G_{rt}^{ch},\\
G_{rt}^{buy}&=G_{rt}^{load}+G_{rt}^{ch},\qquad
G_{rt}^{sell}=R_{rt}^{sell}.
\end{align}

% MMW-ID: CON-Q3-2
储能状态从第 $0$ 小时运行前的初始状态递推：
\begin{align}
S_{r,-1}&=S_r^0,\\
S_{rt}&=S_{r,t-1}+\eta_r^cC_{rt}\Delta t
-\frac{D_{rt}\Delta t}{\eta_r^d},\\
S_r^{min}&\le S_{rt}\le S_r^{max},\\
S_{r,2406}&\ge S_r^0.
\end{align}

% MMW-ID: CON-Q3-3
充放电功率及购售电满足
\begin{align}
0\le C_{rt}&\le C_r^{\max},&
0\le D_{rt}&\le D_r^{\max},\\
0\le G_{rt}^{buy}&\le I_r^{\max}y_{rt}^{grid},&
0\le G_{rt}^{sell}
&\le\min\{X_r^{grid},X_r^{storage}\}(1-y_{rt}^{grid}).
\end{align}
储能充放电及电网购售电均被设置为互斥行为。

% MMW-ID: CON-Q3-4
无储能状态按 $C_{rt}=D_{rt}=0$ 构造。若其违反进口上限，则只记录 \texttt{no\_storage\_\allowbreak baseline\_\allowbreak infeasible}，含储能方案仍从 $S_{r,-1}=S_r^0$ 独立前推。

% MMW-ID: CON-Q3-5
每次储能动作后均检查终端 SOC 的必要可达性：
\begin{equation}
S_{rt}+\sum_{u=t+1}^{2406}\eta_r^cC_r^{\max}\Delta t\ge S_r^0.
\end{equation}
完整轨迹随后接受购电上限、能源守恒、SOC、互斥关系和终端状态审计。

% MMW-ID: CON-Q3-6
净购电、峰值及绝对爬坡量定义为
\begin{align}
N_{rt}&=G_{rt}^{buy}-G_{rt}^{sell},\\
P_r^{peak}&=\max\{0,\max_tN_{rt}\},\\
V_r&=\sum_{t=1}^{2406}|N_{rt}-N_{r,t-1}|.
\end{align}

% MMW-ID: CON-Q3-7
新能源利用率仅在累计可用新能源为正时计算，否则返回结构化不可用状态并退出候选评分。

实际程序采用规则型 SOC 前向策略。无储能与含储能运行成本分别为 $-419820327.7393$ 元和 $-419516103.8102$ 元，成本增加 $304223.9291$ 元。初始 SOC 合计为 $1594.0000$ MWh，终端 SOC 合计为 $3540.0000$ MWh；累计充电量为 $2076.3155$ MWh，累计放电量为 $0$ MWh，且电网充电量为 $0$。无储能与含储能状态的累计购电量均为 $31.5979$ MWh，而累计售电量分别为 $1330267.7686$ MWh 和 $1328783.5422$ MWh。因此，成本增加来自原可售新能源被转化为储能库存后造成的售电收入减少；购电量保持不变，故两种状态的碳排放均为 $8.8506$ tCO$_2$。相应 SOC 轨迹见图~\ref{fig:storage_soc}。

\subsection{问题四：算—储—电联合调度与情景复算}

% MMW-ID: OBJ-Q4
联合模型评价运行成本、碳排放、有效网络时延、有效等待损失、新能源未利用率及六区域非负峰值净购电功率。各维度仅在有定义、数值有限且候选之间存在正尺度时进入代理评分。

% MMW-ID: CON-Q4-1
联合设施负荷由真实任务方案重新构造：

L_{rt}^{F,avg}=\pi_r\left[

任务侧执行问题一的全部硬约束，能源侧执行问题三的能源守恒、SOC、功率和互斥约束。

% MMW-ID: CON-Q4-2
联合初始方案从 $S_{r,-1}=S_r^0$ 独立前推至第 $2406$ 小时，不因问题三无储能比较状态的可行性而停止；若声明预算内未形成完整候选，则返回 \texttt{feasibility\_unresolved}。

% MMW-ID: CON-Q4-3

% MMW-ID: CON-Q4-4

% MMW-ID: CON-Q4-5

% MMW-ID: CON-Q4-6
所有候选在启动前和可中断循环内部检查单调时钟，达到搜索截止后丢弃尚未完成的候选，剩余时间只用于文件输出、完整审计和状态整理。

\subsection{统一约束审计}

任务合法性按
\begin{align}
a_i&\le s_i,\qquad c_i\le F_i,\\
\ell_{o_ir_i}&\le\ell_i^{\max},\\
i\in\mathcal I_{\mathrm{RT}}&\Rightarrow s_i=a_i,\\
\omega_{i,2406}(s_i)&=0
\end{align}
逐项检查。问题二的能源残差以及问题三、四的能源与 SOC 残差分别定义为
\begin{align}
e_{rt}^{q2}
&=G_{rt}^{buy}+R_{rt}^{av}
-L_{rt}^{F,avg}-G_{rt}^{sell}-R_{rt}^{curt},\\
e_{rt}^{energy}
&=G_{rt}^{buy}+R_{rt}^{av}+D_{rt}
-L_{rt}^{F,avg}-C_{rt}-G_{rt}^{sell}-R_{rt}^{curt},\\
e_{rt}^{SOC}
&=S_{rt}-S_{r,t-1}-\eta_r^cC_{rt}\Delta t
+\frac{D_{rt}\Delta t}{\eta_r^d}.
\end{align}
只有任务唯一执行、实时开工、截止、时延、GPU、IT、设施功率、能源守恒、SOC、终端 SOC、购售电互斥、充放电互斥、外送上限及第 $2406$ 小时禁占用全部通过时，才输出全时域可行状态。

% MMW-LIMITATION: L2
任务候选和储能动作的完整局部邻域未被穷举，未检查邻域中可能存在更优可行方案。

% MMW-LIMITATION: L3
